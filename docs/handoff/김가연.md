# 김가연 — 검색·지도 기능 개발

담당(중간보고서): 네이버 지도 API 연동(지도 표시, 현재 위치), 필터링 검색 프로그래밍(하드 필터 → 점수 계산 → 정렬)

> **디자인은 신경 쓰지 않아도 됩니다.** 모든 기능이 끝난 뒤 최원준이 새로 합니다. 기능이 동작하고 화면에 보이기만 하면 됩니다.

## 0. 시작 전 준비

1. 저장소 Collaborator 초대 수락 → 위 README의 실행 방법대로 로컬 실행
2. `python -m pytest` 가 모두 통과하는지 확인
3. 작업마다 새 브랜치: `git switch main && git pull && git switch -c feature/<작업이름>`
4. 끝나면 push → GitHub에서 PR → 최원준 확인 후 merge
5. 파이썬 파일을 고치면 맨 위 `버전 기록`에 한 줄 추가 (예: `# v0.4 (2026-11-20) 현재 위치 반영`)

## 2. 현재 위치

지금은 "대전 중구청 앞"으로 고정되어 있습니다 (`core/geo.py`의 `DEFAULT_ORIGIN`).

- [ ] 브라우저 위치 받기: `navigator.geolocation.getCurrentPosition` → 검색 폼에 숨은 칸 `lat`, `lng` 채우기
- [ ] `app.py`의 `parse_conditions()`에서 `lat`, `lng`를 읽어 `Conditions(origin=(lat, lng))`로 넘기기
- [ ] 위치가 대전 중구 밖이거나 거부되면 기본 위치 사용 (시연은 서울에서 하므로 꼭 필요)
- [ ] 화면의 "현재 위치: 대전 중구청 앞" 문구를 실제 상태에 맞게 바꾸기 (`i18n/*.json`의 `origin_note`)
- [ ] 지도(`public/map.js`)의 출발점 표시도 같은 위치로
