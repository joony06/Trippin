## 공통 원칙

- **프로그래밍은 최원준·김가연만** 합니다. 박한희·김나연은 코드를 다루지 않고, 결과물은 표·문서로 최원준에게 넘깁니다.
- **디자인은 기능이 다 끝난 뒤 최원준이 새로 합니다.** 그 전까지 화면은 기능만 동작하면 됩니다. 색·여백·배치에 시간 쓰지 않기.
- 코드는 `main`에 직접 올리지 않고 **브랜치 → PR → 최원준 확인 후 merge** 순서로 합니다.
- 인증키(`.env`)는 단톡방·문서·저장소 어디에도 붙여 넣지 않습니다.

## 지금 상태 요약

| 기능 (중간보고서) | 상태 |
|---|---|
| 1. 필터링 검색 | 하드 필터(거리·영업시간·예산·대기업 계열·대형 프랜차이즈) → S1~S6 → 정렬·동점·다양성 보정 동작 |
| 2. 소상공인·중소기업 대시보드 | 7일 조회수, 찜, 유입 경로, 내·외국인 비율, 검색어, 업종 평균, 개선 제안 동작 (시연 데이터 없음) |
| 3. 리뷰·평점 | 회원가입·로그인, 1인 1리뷰, 찜, 베이지안 보정 → S6 반영 |
| 4. 다국어 | 화면 문구 4개 국어. 장소 이름은 관광공사 장소 일부만 영문 |
| 장소 데이터 | 공공데이터 3,505곳 (관광공사 107 + 상가정보 3,398). 영업시간·요금·구글 평점은 비어 있음 |
| 지도 | Leaflet + OpenStreetMap (네이버 지도는 카드 등록 시 교체) |

## 실행 방법 (개발자용)

```bash
git clone https://github.com/joony06/Trippin.git && cd Trippin
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt pytest
flask --app app init-db      # data/places.json 으로 DB 생성
flask --app app run --debug  # http://localhost:5000
python -m pytest             # 테스트
```
