# 김나연 — 번역 검수, 시연 영상·썸네일·발표자료, 사용자 테스트

코드는 다루지 않습니다. 결과물은 표·파일로 최원준에게 전달합니다.

## 1. 번역 검수

파일: [번역검수표.csv](번역검수표.csv) — 엑셀이나 구글 시트로 열면 됩니다.

- [ ] 화면 문구 121개를 영어·중국어·일본어로 읽고 어색한 것 표시
- [ ] 고칠 문구는 표의 `고칠 언어`, `고친 문구`, `메모` 칸에 적기 (`key` 칸은 건드리지 않기)
- [ ] `{n}`, `{k}`, `{name}`, `{c}`, `{cat}` 같은 중괄호는 그대로 두기 (숫자·이름이 들어가는 자리)
- [ ] 다 되면 파일을 최원준에게 전달 → 사이트에 반영

## 2. 시연 영상 (유튜브, 3분 내외)

**최종 디자인이 끝난 뒤** 촬영합니다. 시연 계정은 최원준에게 받습니다.

- [ ] 대본 먼저 쓰기 (아래 흐름 추천)
  1. 문제: 관광객이 서울에 몰리고, 지도 앱에서는 광고비 못 내는 작은 가게가 안 보임 (20초)
  2. 검색: 카테고리·검색어·거리·예산으로 찾기 → 대기업·대형 프랜차이즈가 빠진 결과 (40초)
  3. 점수 상세: 왜 이 순서인지 S1~S6 점수표 보여 주기 (30초)
  4. 리뷰·찜: 로그인 → 리뷰 → 보정 평점 (30초)
  5. 사업자 대시보드: 조회수·유입 경로·개선 제안 (30초)
  6. 다국어: 영어·일본어로 바꿔 보기 (15초)
  7. 기대 효과 (15초)
- [ ] 화면 녹화 (Mac: Cmd+Shift+5) + 목소리 또는 자막
- [ ] 유튜브 업로드 (일부 공개) → 링크를 팀에 공유

## 3. 썸네일 1장 (구글폼 제출)

- [ ] 로고(`public/logo-wordmark.png`) + 한 줄 소개 + 대표 화면 캡처
- [ ] 한 줄 소개 예: "광고가 아닌, 나에게 맞는 순서로 찾는 지방 로컬 여행"

## 4. 발표자료 8쪽

- [ ] 문제 → 해결 방법 → 기능 4개 → 점수 계산 → 결과 화면 → 기대 효과 → 팀 구성
- [ ] 최종보고서 내용과 맞추기 (박한희와 확인)

## 5. 사용자 테스트 (박한희와 함께)

박한희 문서의 3번과 같은 표 형식으로 기록 → 최원준에게 전달. 특히 **영어·중국어·일본어 화면**에서 이상한 점을 중심으로 봐 주세요.
