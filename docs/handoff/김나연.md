코드는 다루지 않습니다. 결과물은 표·파일로 최원준에게 전달합니다.
마감: **11/23(월) 01:00**, 목표는 **일요일 24:00 제출** (마감 01:00까지 1시간 여유). 영상·썸네일·발표자료도 같은 마감으로 간주합니다 (박한희가 오늘 낮에 확인). 공통 규칙은 [README.md](README.md)에 있습니다.

> **목·금·토·일 모두 가능하므로 역할이 늘었습니다.** 박한희가 일요일에 할머니 생신이라, **일요일 보고서 마무리(2장 확정, 4장 캡처 삽입, 쪽수 확인, PDF)를 김나연이 맡습니다.** 박한희는 토요일 24:00까지 초안을 넘기고, 일요일 저녁 늦게 온라인으로 PDF 검토만 합니다 (21:30에 PDF를 박한희에게도 보내고, 오타·사실 오류 목록은 22:30까지 받아 반영).

> 일정은 각자 유동적으로 바꿔도 됩니다. 다른 사람이 기다리는 전달 기한이 바뀌면 단톡방에 미리 알려 주세요.

- [ ] 화면 문구 121개를 영어·중국어·일본어로 읽고 어색한 것 표시
- [ ] 고칠 문구는 표의 `고칠 언어`, `고친 문구`, `메모` 칸에 적기 (`key` 칸은 건드리지 않기)

## 3. 시연 영상 (유튜브, 3분 내외)

**두 번 찍습니다: 토요일에 백업 영상, 일요일 18:00에 최종 영상.** 일요일에 디자인이 늦어지거나 문제가 생겨도 제출할 영상이 남도록 하기 위해서입니다.

시연 계정과 접속 방법은 최원준에게 받습니다 (일요일 10:30까지 최종 계정 확정). 토요일 백업 영상에 계정이 없으면 **대시보드 장면을 빼고** 찍고, 일요일 최종 영상에서 넣습니다.

- [ ] **금요일까지 대본 먼저 쓰기** (아래 흐름 추천)
  1. 문제: 관광객이 서울에 몰리고, 지도 앱에서는 광고비 못 내는 작은 가게가 안 보임 (20초)
  2. 검색: 카테고리·검색어·거리·예산으로 찾기 → 대기업·대형 프랜차이즈가 빠진 결과 (40초)
  3. 점수 상세: 왜 이 순서인지 S1~S6 점수표 보여 주기 (30초)
  4. 리뷰·찜: 로그인 → 리뷰 → 보정 평점 (30초)
  5. 사업자 대시보드: 조회수·유입 경로·개선 제안 (30초)
  6. 다국어: 영어·일본어로 바꿔 보기 (15초)
  7. 기대 효과 (15초)
- [ ] **토요일: 백업 영상 촬영** (현재 화면, 3분 이내) → 일단 유튜브에 일부 공개로 올려 두기
- [ ] **일요일 18:00~20:00: 최종 영상 재촬영** (디자인 끝난 화면). 최원준이 16:30에 "배포 확인 끝, 이 주소로 찍어"라고 알려 줌
- [ ] 화면 녹화 (Mac: Cmd+Shift+5) + 목소리 또는 자막
- [ ] 편집·업로드 (일 20:00~21:30) → 링크를 **22:00까지** 최원준에게 전달 (일부 공개)
- 토요일 밤에 **지도가 네이버 지도로 바뀝니다.** 토요일 백업 영상은 기존 지도(OSM)로 찍히고, 일요일 최종 재촬영에서는 네이버 지도가 나옵니다. 재촬영 때 지도 장면(마커·현재 위치)이 정상인지 확인하세요.
- 촬영하면서 영·일 화면에서 깨지는 곳을 발견하면 바로 최원준에게 알려 주세요 (치명적인 것만, 19:00 이전에).
- 최종 영상이 22:00까지 안 되면 **백업 영상 링크를 제출**합니다.
