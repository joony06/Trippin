## 1. 데이터 만드는 흐름

```
① 원본 수집 (공공데이터 API)
   ├ collect_sbiz.py   소상공인시장진흥공단 상가(상권)정보: 대전 중구 상가 + 대전 전체(체인 판정용)
   └ collect_tour.py   한국관광공사 TourAPI 국문·영문 관광정보 + 장소별 개요(overview)
      │
      ▼
② 보강 (외부 API)
   ├ collect_google.py   Google Places: 평점·리뷰 수·영업시간 (무료 한도 안에서 일부 장소만)
   └ gen_descriptions.py Gemini: 관광공사 개요로 한국어·영어 소개문 생성
      │
      ▼
③ build_places.py   하나의 장소 목록(data/places.json)으로 합치기
   - 관광객이 갈 만한 업종만 남김 (음식·카페 등), 구내식당·기관·단체 제외
   - 관광공사 장소와 상가가 겹치면(이름 비슷 + 100m 이내) 하나만
   - 앱 카테고리로 변환 (역사·자연·음식·카페·사진명소·야경·쇼핑·문화·액티비티·가족)
   - 대기업 계열·대형 체인 표시 (아래 2절)
   - 검수표 판정 반영 (아래 3절)
      │
      ▼
④ 앱 실행 시 db.py가 places.json을 SQLite DB에 적재 + 시연용 데모 데이터(seed_demo.py)
```

## 2. 대기업 계열·대형 체인 판정

| 구분 | 기준 | 파일 |
|---|---|---|
| 대기업 계열 | 공정위 지정 공시대상기업집단 소속 회사가 운영하는 브랜드 (상호에 브랜드 이름이 들어가면) | `conglomerate_brands.txt` (20개) |
| 대형 체인 | ① 대전 전체에서 지점명이 붙은 같은 상호가 10곳 이상 ② 대기업은 아니지만 전국 체인 브랜드(SPC 등) | `chain_brands.txt` + 자동 계산 |
| 가게별 판정 | 팀원이 3,490곳을 전부 확인한 결과(검수표 「가게목록」) | `store_verdicts.json` |

- 철자가 다른 상호(파리바게트·베스킨라빈스)도 같은 브랜드로 판정합니다.
- '한화·하나로·삼성·현대'처럼 동네 가게 이름에도 들어가는 이름은 브랜드 목록에 넣지 않고, 해당 매장만 가게별 판정으로 처리했습니다.
- 대기업 계열과 대형 체인은 지도·검색에서 모두 빠집니다(하드 필터). 화면의 '제외된 곳'에 이유가 표시됩니다.

## 3. 검수표 반영 (박한희·김나연, 11/21)

- 3,490곳 전부 확인: 정상 2,893 · 대형체인 440 · 대기업 37 · 기관 6 · 판단 보류 114
- 대기업·대형체인 → 제외, 기관 → 데이터에서 삭제, 판단 보류 → 지도에 그대로 둠
- 브랜드표: SPC 4개 브랜드는 공시대상기업집단이 아니라 대형 체인으로 분류. 노브랜드(이마트), 롯데하이마트, LG전자 베스트샵, 이랜드(애슐리·로운·NC), 정관장(KT&G) 추가

## 4. 최종 숫자

| 항목 | 값 |
|---|---|
| 전체 장소 | 3,484곳 (관광공사 107 + 상가정보 3,377) |
| 지도·검색에 나오는 곳 | 3,007곳 (관광공사 84 + 상가정보 2,923) |
| 제외 | 대기업 37 · 대형체인 440 · 기관 6(삭제) |
| 관광지 카테고리 | 역사 9 · 자연 11 · 야경 3 (관광지 이름 기준 보강 포함) |
| 구글 평점·리뷰 수 | 850곳 요청 → 634곳 매칭 (지도에 나오는 곳 중 516곳). 영업시간은 369곳 |
| AI 소개문 | 관광공사 장소 대상, Gemini 서버 혼잡으로 생성 중 (생성 후 갱신) |

## 5. 데이터가 없을 때 처리

- 영업시간이 없으면 영업시간 필터에서 빼지 않음
- 구글 평점·리뷰 수가 없으면 S4·S5에 중립값 0.5
- 요금은 수집하지 않아 '정보 없음'으로 표시, 예산 필터는 0원으로 봄
- 상가정보에는 영문 이름이 없어서 관광공사 장소만 영문 이름이 있음

## 6. 시연용 데모 계정 (seed_demo.py)

| 계정 | 비밀번호 | 용도 |
|---|---|---|
| demo_owner | trippin-demo | 사업자 대시보드 (미소본가스마일칼국수) |
| demo_kr1 · demo_us1 · demo_jp1 등 8개 | trippin-demo | 관광객 (리뷰·찜 확인) |

- 최근 7일 조회 기록, 찜 4개, 리뷰 4개(한·영·일)가 자동으로 들어감. 시연용 예시 값이라고 보고서에 밝힐 것.
- 배포 사이트(Vercel)는 서버가 새로 뜰 때마다 DB가 처음 상태로 돌아가므로, 새로 가입한 계정·리뷰는 사라질 수 있음 → 보완점.

## 7. 보완점 (데이터 쪽)

- 구글 데이터는 무료 한도 때문에 관광공사 장소 + 상위 후보 850곳만 요청(634곳 매칭) → 나머지는 S4·S5 중립값 0.5, 영업시간 필터 미적용
- 요금 정보 미수집
- 동네 이름·상가 이름은 외국어 화면에서도 한글
- 판단 보류 114곳은 체인 여부 미확정
- 전국 가맹점 수 API(공정위)는 가명정보 승인이 필요해 대전 지점 수로 대신 판정
